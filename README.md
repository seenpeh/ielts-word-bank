# IELTS word bank

A free, single-page study tool for IELTS Writing and Speaking vocabulary. It runs entirely in the browser, with no build step and no server.

**Live site:** https://seenpeh.github.io/ielts-word-bank/

## What's inside

- **Flashcards**: spaced-repetition review (daily review and free practice) of about 270 words and phrases, with English and Persian meanings, example sentences and usage notes.
  - Task 1 charts, Task 2 essays, linking words and Listening vocabulary
  - Keyboard control: tap Space to flip, hold Space for "Got it", double-tap Space for "Again"
- **Paraphrasing**: read a meaning in Persian, then reveal many English rephrases grouped by grammar pattern.
- **Words**: the full list by category, or by use (groups of words and phrases you can swap for each other, with example rewrites).

Progress is saved in your browser's local storage, so it stays on the device you use.

## Run it locally

Open `index.html` in any modern browser.

## Deploy

The site is served by GitHub Pages from the `main` branch, root folder.
